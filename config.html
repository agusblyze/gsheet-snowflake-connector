Required
From your Snowflake URL: https://<account>.snowflakecomputing.com
Generate in Snowflake: User menu → Programmatic access tokens → Generate
Optional Defaults
Notifications
If set, a Slack message is sent when an auto-refresh query fails after all retries.
How to get a PAT:
1. Log into Snowflake
2. Click your name (bottom-left)
3. Select "Programmatic access tokens"
4. Click "+ Generate" and copy the token
